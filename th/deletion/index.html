คำแนะนำการลบข้อมูล

TAIPOPO

แก้ไขล่าสุด: 2026-11-23

1. บัญชีแอป

TAIPOPO ไม่ได้สร้างหรือให้บริการบัญชีแอปแยกต่างหาก

2. ข้อมูลที่จัดเก็บภายในแอป

ข้อมูลสถานที่ทำงาน ข้อมูลคนทำงาน บันทึกการลงเวลาและงาน ภาพถ่าย การคำนวณยอดชำระ รายงาน PDF การตั้งค่าแอป ไฟล์แนบ และไฟล์ที่เกี่ยวข้องกับ export/backup จะจัดเก็บโดยหลักในพื้นที่จัดเก็บของแอปบนอุปกรณ์ จากการตรวจสอบการทำงานปัจจุบัน แอปไม่ได้มีโครงสร้างที่อัปโหลดและเก็บบันทึกการทำงานของผู้ใช้ไว้บนเซิร์ฟเวอร์ของแอปเอง

3. การลบข้อมูลภายในแอป

บันทึกสามารถลบแยกตามแต่ละฟังก์ชันได้ ภาพถ่ายสามารถย้ายไปถังขยะ กู้คืน หรือลบถาวรได้ ข้อมูลที่แอปจัดการและจัดเก็บบนอุปกรณ์สามารถลบได้จากเส้นทางต่อไปนี้

การตั้งค่า > การจัดการข้อมูล > รีเซ็ตข้อมูลทั้งหมด

ล้างข้อมูลทั้งหมดจะลบการตั้งค่าแอป ข้อมูลการทำงาน ภาพถ่ายภายในแอป PDF ที่สร้างในแอป ไฟล์แนบภายในแอป ข้อมูล export/backup ภายในแอป และข้อมูล cache/temp เมื่อการลบเสร็จสิ้น แอปอาจปิดลง และหากไม่มีข้อมูลสำรองที่เก็บไว้แยกต่างหาก ข้อมูลแอปภายในอุปกรณ์ที่ลบแล้วจะไม่สามารถกู้คืนได้

4. การลบแอป

เมื่อผู้ใช้ลบแอป ข้อมูลในพื้นที่จัดเก็บของแอปบนอุปกรณ์อาจถูกลบตามนโยบายของระบบปฏิบัติการ อย่างไรก็ตามไม่ได้หมายความว่าไฟล์ที่ส่งออกหรือคัดลอกออกนอกแอป หรือสำเนาที่เก็บไว้ในแอปอื่นหรืออุปกรณ์จัดเก็บอื่นจะถูกลบทั้งหมด ก่อนลบแอป โปรดสำรองข้อมูลที่จำเป็นหรือจัดการสำเนาภายนอกด้วยตนเอง

5. ไฟล์ ZIP สำรองและสำเนาภายนอก

รุ่นที่อยู่ระหว่างการตรวจสอบนี้ไม่มีการเชื่อมโยงบัญชี Google การสำรองหรือกู้คืนโดยตรงผ่าน Drive API หรือการอัปโหลดต่อโดยอัตโนมัติ TAIPOPO สร้างไฟล์ ZIP สำรองในอุปกรณ์ เมื่อส่งออก ระบบจะส่งไฟล์ให้แอปที่คุณเลือกในเมนูแชร์ คุณสามารถจัดการหรือลบสำเนาภายนอกจากตำแหน่งที่บันทึกไว้ได้ หลังจากสร้างไฟล์ ZIP สำรองแล้ว ให้เลือกแอปที่จะใช้เก็บไฟล์จากเมนูแชร์ของ Android ตรวจสอบสถานะการบันทึกในแอปที่เลือก และเก็บไฟล์ทุกส่วนของข้อมูลสำรองแบบแบ่งไฟล์ไว้ด้วยกัน เลือกไฟล์ ZIP สำรองจากอุปกรณ์หรือพื้นที่จัดเก็บที่แสดงในตัวเลือกไฟล์ ข้อมูลสำรองแบบแบ่งไฟล์ต้องใช้ไฟล์ทุกส่วนจากชุดเดียวกัน สำเนา Google Drive จากเวอร์ชันเก่า: หากเวอร์ชันก่อนหน้าสร้างข้อมูลสำรองใน appDataFolder ไว้ สำเนาภายนอกนั้นแยกจาก ZIP ของเวอร์ชันปัจจุบัน การรีเซ็ตหรือถอนการติดตั้งแอปไม่ลบสำเนานั้น เวอร์ชันนี้ ไม่มีฟังก์ชันสำรอง กู้คืน หรือจัดการสำเนานั้นโดยตรง โปรดดูคำแนะนำอย่างเป็นทางการของ Google สำหรับการจัดการหรือลบสำเนาในบัญชี Google ที่เป็นเจ้าของ https://support.google.com/drive/answer/6374270

6. ไฟล์ภายนอกแอป

ไฟล์ที่ส่งออกไปยัง Downloads ไฟล์ที่แชร์ไปยังแอปอื่น ไฟล์ที่ส่งทางอีเมล ไฟล์ที่คัดลอกไปยัง cloud, USB หรืออุปกรณ์จัดเก็บภายนอก หรือ ZIP/PDF/ภาพถ่ายที่ผู้ใช้เก็บไว้แยกต่างหาก อาจยังคงอยู่แยกจากการลบข้อมูลภายในแอป ต้องลบสำเนาเหล่านั้นแยกต่างหากจากตำแหน่งที่จัดเก็บหรือบริการที่รับไฟล์

7. ข้อมูลวินิจฉัย Firebase Crashlytics

การล้างข้อมูลภายในแอปหรือถอนการติดตั้งแอปจะไม่ลบข้อมูลวินิจฉัยที่ส่งไปยัง Firebase Crashlytics แล้วโดยอัตโนมัติ

แอปนี้ไม่ได้กำหนดรหัสผู้ใช้ที่กำหนดเองใน Crashlytics ฝ่ายสนับสนุน Firebase ยืนยันว่าในการตั้งค่านี้ไม่สามารถใช้ FID หรือตัวระบุการติดตั้ง Crashlytics เพื่อค้นหาหรือลบรายงานเก่าของผู้ใช้รายใดรายหนึ่งได้ การลบ FID ไม่ลบรายงานที่ส่งไปแล้ว ข้อจำกัดนี้ไม่รวมการลบอีเมลสนับสนุนหรือบันทึกงานในอุปกรณ์

8. สำรองข้อมูลก่อนลบ

เก็บบันทึกงาน การตั้งค่า รูปภาพ และข้อมูลอื่น ๆ ไว้ในอุปกรณ์เป็นไฟล์ ZIP สำรอง หลังจากสร้างไฟล์ ZIP สำรองแล้ว ให้เลือกแอปที่จะใช้เก็บไฟล์จากเมนูแชร์ของ Android ตรวจสอบสถานะการบันทึกในแอปที่เลือก และเก็บไฟล์ทุกส่วนของข้อมูลสำรองแบบแบ่งไฟล์ไว้ด้วยกัน การกู้คืนอาจแทนที่ข้อมูลปัจจุบันบนอุปกรณ์ด้วยเนื้อหาจากข้อมูลสำรอง

9. ขั้นตอนการลบและการติดต่อ

ลบข้อมูลแอปในอุปกรณ์ได้ด้วยล้างข้อมูลทั้งหมดตามขั้นตอนข้างต้น หากต้องการความช่วยเหลือ โปรดติดต่ออีเมลด้านล่าง

ติดต่อ: taipopo.app@gmail.com

ผู้ดำเนินการใช้เฉพาะข้อมูลที่จำเป็นต่อการจัดการคำขอความช่วยเหลือ เมื่อให้คำตอบและดำเนินการติดตามที่จำเป็นเสร็จสิ้นจนบรรลุวัตถุประสงค์ในการประมวลผลแล้ว จะลบข้อมูลคำขอความช่วยเหลือและไฟล์แนบโดยไม่ชักช้า อีเมลที่ได้รับและอีเมลตอบกลับจะถูกลบออกจากบัญชีอย่างถาวร รวมถึงสำเนาที่ผู้ดำเนินการจัดการ เช่น ไฟล์ที่ดาวน์โหลดด้วย เฉพาะบันทึกที่มีหน้าที่ต้องเก็บรักษาตามกฎหมายจริงเท่านั้นที่จะเก็บแยกจากคำขอความช่วยเหลืออื่นตามระยะเวลาที่กฎหมายกำหนด

ส่งคำขอลบข้อมูลไปที่ taipopo.app@gmail.com คำขอจะได้รับการดำเนินการหลังจากยืนยันตัวตนหรืออำนาจของผู้แทนที่มีสิทธิ โดยใช้ข้อมูลเท่าที่จำเป็นขั้นต่ำ บันทึกที่กฎหมายกำหนดให้เก็บรักษาจะได้รับยกเว้นจากการลบเฉพาะขอบเขตที่หน้าที่นั้นมีผลใช้บังคับ พร้อมแจ้งฐานกฎหมายและระยะเวลาเก็บรักษา กระบวนการนำข้อมูลออกจากเซิร์ฟเวอร์และข้อมูลสำรองของผู้ให้บริการ Gmail แยกจากการลบสำเนาที่ผู้ดำเนินการจัดการ

ผู้ดำเนินการใช้ Gmail เพื่อรับ เก็บรักษา และตอบอีเมลขอความช่วยเหลือ การจัดการและลบคำขอโดยผู้ดำเนินการอยู่ภายใต้นโยบายนี้ บริการอีเมลที่ผู้ส่งเลือกก็มีส่วนร่วมในการส่ง และการประมวลผลของแต่ละบริการอีเมลเองอยู่ภายใต้นโยบายของบริการนั้นด้วย

คำขอความช่วยเหลือที่จำเป็นต่อการปฏิบัติตามสัญญาใช้งานแอป หรือการดำเนินการที่คุณร้องขอระหว่างการทำสัญญา จะประมวลผลตามมาตรา 15(1)(4) ของกฎหมายคุ้มครองข้อมูลส่วนบุคคลของเกาหลีใต้ คำขอใช้สิทธิด้านข้อมูลส่วนบุคคลจะประมวลผลตามมาตรา 15(1)(2) และบทบัญญัติที่เกี่ยวข้องในมาตรา 35–38 โดยประมวลผลเฉพาะที่อยู่อีเมลผู้ส่ง เนื้อหาคำขอ และเอกสารที่เกี่ยวข้องซึ่งจำเป็นต่อแต่ละคำขอเท่านั้น ไม่ใช้ฐานเหล่านี้ครอบคลุมข้อเสนอแนะทั่วไปหรือไฟล์แนบที่ไม่จำเป็นทั้งหมด

ตัวเลือกความเป็นส่วนตัวเก็บแยกบนอุปกรณ์และไม่รวมในข้อมูลสำรอง ZIP การรีเซ็ตทั้งหมดจะคืนสถานะเริ่มต้น การถอนวินิจฉัยและรีเซ็ตแอป ไม่ใช่การลบแบบเดียวกันสำหรับวินิจฉัยที่ส่งแล้ว หรือสำเนาที่แชร์ภายนอก คำขอลบรายงานที่ยังไม่ส่งไม่ได้ยืนยันว่าลบคิว SDK ทั้งหมดแล้ว ติดต่อเพื่อขอลบข้อมูลที่ส่งแล้ว โดยต้องตรวจสอบขอบเขตจริงตามบริการและกฎหมายที่ใช้บังคับ

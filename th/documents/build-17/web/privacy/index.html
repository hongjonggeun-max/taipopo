รายการเอกสารของบิลด์ 17หน้าเงื่อนไขการใช้งานที่ใช้ร่วมกันหน้านโยบายความเป็นส่วนตัวที่ใช้ร่วมกัน

เอกสารที่เผยแพร่บนเว็บไซต์ในขณะนั้น

สำเนาเหล่านี้เก็บรักษาไว้โดยเปรียบเทียบซอร์สของเว็บไซต์ที่เผยแพร่เมื่อ 2026-11-20 กับเอกสารตอบกลับ HTTP ที่เก็บไว้

เอกสารที่แสดงในแอปมีเนื้อหาต่างจากเอกสารที่เผยแพร่บนเว็บไซต์ในขณะนั้น หลักฐานที่มีอยู่ยังไม่สามารถยืนยันได้ว่าเอกสารใดใช้กับบิลด์ 17

วันที่ในเอกสารคือวันที่ที่แสดงในขณะนั้น ไม่ใช่วันที่มีผลบังคับใช้ใหม่

ในบิลด์ 17 การค้นหาที่อยู่ของสถานที่ทำงานต้องได้รับอนุญาตแยกต่างหากผ่านหน้าต่างป๊อปอัปในแอป เนื้อหานโยบายความเป็นส่วนตัวในแอปขณะนั้นมีคำอธิบายทั่วไปเกี่ยวกับการแปลงพิกัดเป็นที่อยู่ แต่ไม่ได้ระบุขั้นตอนการขออนุญาตล่วงหน้านี้อย่างชัดเจน

เนื้อหาเอกสารที่เก็บรักษาไว้

วันที่มีผล: 2026-08-23 แก้ไขล่าสุด: 2026-11-20 ผู้ควบคุมข้อมูลส่วนบุคคลและผู้รับผิดชอบด้านการคุ้มครองข้อมูลส่วนบุคคล: นักพัฒนาอิสระ Jonggeun Hong TAIPOPO 1.0.0 (17) วิธีสแกนรหัส QR และการประมวลผลข้อมูลการวินิจฉัยที่เกี่ยวข้องจะแตกต่างกันไปตามเวอร์ชันของแอป 1. ผู้ควบคุมข้อมูลส่วนบุคคลและช่องทางติดต่อ ผู้ควบคุมข้อมูลส่วนบุคคลและผู้รับผิดชอบด้านการคุ้มครองข้อมูลส่วนบุคคล: นักพัฒนาอิสระ Jonggeun Hong สามารถส่งคำถามเกี่ยวกับการประมวลผลข้อมูลส่วนบุคคล ขั้นตอนการลบข้อมูลแอป และการใช้สิทธิไปยังที่อยู่อีเมลด้านล่างได้ taipopo.app@gmail.com 2. ข้อมูลที่ประมวลผล TAIPOPO จัดเก็บข้อมูลที่จำเป็นต่อการจัดการการลงเวลาทำงาน สถานที่ทำงาน บันทึกภาพถ่าย การคำนวณยอดชำระ และรายงาน โดยหลักอยู่ในพื้นที่จัดเก็บของแอปบนอุปกรณ์ของผู้ใช้ จากการตรวจสอบการทำงานปัจจุบัน TAIPOPO ไม่ได้มีโครงสร้างที่อัปโหลดและเก็บข้อมูลการทำงานของผู้ใช้ไว้บนเซิร์ฟเวอร์ของ TAIPOPO เอง ข้อมูลผู้ใช้และคนทำงาน: ชื่อคนทำงาน หมายเลขโทรศัพท์ อีเมล ที่อยู่และที่อยู่โดยละเอียด เกณฑ์คำนวณค่าจ้าง วันที่จ่าย วิธีจ่าย ธนาคาร เลขบัญชี และชื่อผู้ถือบัญชี ข้อมูลสถานที่ทำงาน: ชื่อสถานที่ทำงาน ที่อยู่และที่อยู่โดยละเอียด ชื่อบริษัท ชื่อผู้รับผิดชอบ ข้อมูลติดต่อ บันทึกของสถานที่ทำงาน และไฟล์แนบของสถานที่ทำงาน ข้อมูลการลงเวลาและงาน: เวลาเข้างานและออกงาน เวลาทำงานและเวลาพัก บันทึกงาน ข้อมูลการคำนวณยอดชำระ ข้อมูลรายงาน และ สำเนาสถานะของบันทึก ที่เกี่ยวข้อง ข้อมูลภาพถ่ายและรูปภาพ: รวมถึงภาพถ่ายต้นฉบับ ภาพที่แก้ไขแล้ว ภาพสำหรับแสดงผล ภาพขนาดย่อและภาพอนุพันธ์อื่น ๆ หมวดหมู่ภาพที่ผู้ใช้กำหนด ข้อมูลเครื่องหมายและข้อมูลคำอธิบายประกอบภาพที่เพิ่มลงในภาพ เวลาถ่ายภาพ และข้อมูลสถานที่ทำงานหรืองานที่เชื่อมโยงกับภาพ ข้อมูลตำแหน่งและที่อยู่: พิกัด GPS และข้อมูลที่อยู่เมื่อผู้ใช้อนุญาตตำแหน่งและใช้ฟังก์ชันที่เกี่ยวข้อง โดยแอปเรียกใช้บริการแปลงพิกัดเป็นที่อยู่ของระบบปฏิบัติการ Android และกระบวนการนี้อาจใช้เครือข่าย ทั้งนี้ขึ้นอยู่กับการกำหนดค่าของอุปกรณ์และระบบปฏิบัติการ กล้องอาจขอแปลงพิกัดเป็นที่อยู่เมื่อเปิดการแสดงที่อยู่ ได้รับสิทธิ์เข้าถึงตำแหน่ง และมีพิกัดที่ใช้ได้ การเปิดบันทึก GPS เพียงอย่างเดียวจะไม่ขอแปลงที่อยู่ ข้อมูลกำกับภาพ: ไฟล์ภาพต้นฉบับอาจมีข้อมูลกำกับที่เกี่ยวข้องกับการถ่ายภาพ (ข้อมูลเพิ่มเติมของภาพ) เช่น EXIF แอปอาจอ่านข้อมูลทิศทางของภาพหรือนำไปใช้กับภาพอนุพันธ์เพื่อแสดงและแชร์ภาพ รวมถึงสร้าง PDF การตั้งค่าและการวินิจฉัย: การตั้งค่าแอป การแจ้งเตือน กล้อง และการสำรองข้อมูล ข้อมูลความคืบหน้าของการสำรองและกู้คืน และข้อมูลเสถียรภาพกับการวินิจฉัยข้อผิดพลาดของแอป การค้นหาที่อยู่ในกล้องต้องเปิดแสดงที่อยู่ มีตำแหน่งที่แม่นยำซึ่งใช้งานได้ และเลือกอนุญาตการค้นหาแยกต่างหาก การบันทึก GPS เพียงอย่างเดียวไม่ขอที่อยู่ คำขอ GPS ของสถานที่ทำงานทุกครั้งจะแจ้งว่าอาจประมวลผลนอกอุปกรณ์และขออนุญาตก่อนเข้าถึงพิกัด แม้ได้รับสิทธิ์ Android แล้วก็ตาม การค้นหาที่อนุญาตอาจใช้ตำแหน่งที่แม่นยำหรือโดยประมาณ หากปฏิเสธ คุณยังป้อนที่อยู่เองได้ ที่อยู่สถานที่ทำงานล่าสุดและตำแหน่งที่เกี่ยวข้องอาจคงอยู่ชั่วคราวในหน่วยความจำของแอป หากผ่านเงื่อนไขอายุ ความแม่นยำ และระยะทางของตำแหน่ง จะนำที่อยู่กลับมาใช้ภายใน 30 วินาทีหลังค้นหาเสร็จได้โดยไม่ขอแปลงพิกัดใหม่ 30 วินาทีเป็นขีดจำกัดการนำกลับมาใช้ ไม่ใช่กำหนดเวลาลบจากหน่วยความจำ แคชนี้ไม่ถูกเขียนลงไฟล์หรือข้อมูลสำรองและไม่ใช้กับที่อยู่ของกล้อง ที่อยู่สถานที่ทำงานที่คุณเลือกบันทึกจะเก็บแยกไว้ในอุปกรณ์ 3. วัตถุประสงค์และหลักในการประมวลผล ข้อมูลข้างต้นได้มาจากการที่ผู้ใช้ป้อนข้อมูล ถ่ายภาพ แนบข้อมูลในแอป หรือเรียกใช้ฟังก์ชันด้วยตนเอง ข้อมูลเหล่านี้ใช้เพื่อจัดการบันทึกการลงเวลาและงาน เก็บบันทึกภาพถ่าย คำนวณยอดชำระ สร้างรายงานและ PDF สำรองและกู้คืนข้อมูล แจ้งเตือน วินิจฉัยข้อผิดพลาด และตอบข้อสอบถาม แอปใช้ตำแหน่ง กล้อง การแจ้งเตือน และพื้นที่จัดเก็บตามสิทธิ์ Android และการเลือกของผู้ใช้ 4. ระยะเวลาจัดเก็บ ข้อมูลการทำงานและภาพถ่ายอาจอยู่ในพื้นที่จัดเก็บของแอปจนกว่าผู้ใช้จะลบรายการ ลบภาพถาวร ล้างข้อมูลทั้งหมด ถอนการติดตั้งแอป หรือล้างข้อมูลแอปผ่านระบบปฏิบัติการ โดยใช้กฎและข้อยกเว้นของถังขยะในข้อ 10 ร่วมด้วย การล้างข้อมูลทั้งหมดจะลบการตั้งค่า ข้อมูลการทำงาน ภาพถ่าย PDF ที่สร้างขึ้น ไฟล์แนบ ไฟล์ส่งออกและข้อมูลสำรองภายในแอป และข้อมูลแคชและไฟล์ชั่วคราวในพื้นที่ที่แอปจัดการบนอุปกรณ์ สำเนาที่จัดเก็บไว้นอกพื้นที่ที่แอปจัดการต้องลบแยกต่างหาก ข้อมูลวินิจฉัยที่ส่งไปยัง Firebase Crashlytics จะได้รับการจัดการตามฟังก์ชันและนโยบายของ Firebase 5. ไฟล์ ZIP สำรองและสำเนาภายนอก TAIPOPO สร้างไฟล์ ZIP สำรองในอุปกรณ์ เมื่อส่งออก ระบบจะส่งไฟล์ให้แอปที่คุณเลือกในเมนูแชร์ คุณสามารถจัดการหรือลบสำเนาภายนอกจากตำแหน่งที่บันทึกไว้ได้ ไฟล์ ZIP มาตรฐานนี้เป็นสำเนาข้อมูลแอปทั้งหมดที่ไม่ได้เข้ารหัส อาจมีรูปภาพต้นฉบับและข้อมูลเมตาตำแหน่ง เวลาในการถ่าย และอุปกรณ์ รวมถึงสถานที่ทำงาน ที่อยู่ บันทึกการทำงาน ค่าจ้าง และบันทึกย่อ การบันทึกหรือแชร์จะสร้างสำเนานอกแอปที่บุคคลหรือแอปที่เลือกสามารถเปิดได้ เวอร์ชัน 1.0.0(17) ไม่มีการเชื่อมต่อบัญชี Google การสำรองหรือกู้คืนโดยตรงผ่าน Drive API หรือการอัปโหลดต่ออัตโนมัติ ZIP สำรองจะสร้างในอุปกรณ์และบันทึกไว้ในอุปกรณ์หรือที่จัดเก็บภายนอกได้ เมื่อส่งออกข้อมูลสำรองภายนอก ให้เลือกแอปรับข้อมูลในเมนูแชร์ของ Android เมื่อต้องการกู้คืน ให้เลือกข้อมูลสำรองจากรายการสำรองในอุปกรณ์หรือจากตัวเลือกไฟล์ ข้อมูลสำรองใน Drive appDataFolder ที่สร้างด้วยเวอร์ชันเก่าแยกจาก ZIP ทั่วไปที่บันทึกผ่านการแชร์ และจะไม่ถูกลบอัตโนมัติเมื่ออัปเดตหรือรีเซ็ตข้อมูลในเครื่อง เวอร์ชันนี้ไม่สามารถแสดงรายการหรือลบข้อมูลสำรองเก่าเหล่านั้นโดยตรงได้ โปรดติดต่อฝ่ายสนับสนุนหากต้องการความช่วยเหลือ 6. Firebase Crashlytics การวินิจฉัย Firebase Crashlytics ปิดอยู่ตามค่าเริ่มต้น หากอนุญาต อาจส่งรหัสข้อผิดพลาด เส้นทางการเรียกที่ล้างข้อมูลแล้ว ตัวระบุการติดตั้ง SDK และข้อมูลวินิจฉัยอุปกรณ์และแอปไปยัง Google Firebase แอปไม่ส่งบันทึกงาน รูปภาพ หรือข้อความสอบถามเป็นเนื้อหาวินิจฉัย คุณยังใช้บันทึก กล้อง และการสำรองข้อมูลได้โดยไม่อนุญาต การถอนจะบล็อกรายงานข้อผิดพลาดใหม่จากแอป แต่เรียกคืนการส่ง SDK ที่กำลังดำเนินอยู่ไม่ได้ ก่อนเริ่ม Firebase อีกครั้งหลังถอนหรือย้ายข้อมูลในการอัปเดตครั้งนี้ จะลบรายงาน Crashlytics ที่คงอยู่และคิวการวินิจฉัยเซสชัน Firebase หากล้างไม่สำเร็จจะไม่เปิดรายงานข้อผิดพลาด Firebase การอนุญาตอีกครั้งในกระบวนการเดิมจะรอปิดกระบวนการทั้งหมดและเริ่มใหม่พร้อมล้าง เพื่อไม่ส่งรายงานย้อนหลังจากช่วงที่ปิด การลบข้อมูลที่ส่งถึงเซิร์ฟเวอร์แล้วต้องร้องขอแยก ตัวเลือกนี้ไม่ควบคุมการวินิจฉัย ML Kit การวินิจฉัยทางเทคนิค ML Kit ที่คงอยู่อาจส่งแยกต่างหาก ข้อมูลวินิจฉัย Crashlytics แยกจากบันทึกงาน ภาพถ่าย และข้อมูลการคำนวณยอดชำระของผู้ใช้ การล้างข้อมูลภายในแอปหรือถอนการติดตั้งแอปจะไม่ลบข้อมูลวินิจฉัยที่ส่งไปยัง Firebase Crashlytics แล้วโดยอัตโนมัติ สามารถส่งคำถามที่เกี่ยวข้องไปยังอีเมลด้านล่าง และขอบเขตการดำเนินการจริงอาจแตกต่างไปตามฟังก์ชันและนโยบายของ Firebase ตามคำแนะนำอย่างเป็นทางการของ Firebase นั้น Crashlytics จะเก็บบันทึกลำดับการเรียกใช้ ณ

데이터 삭제 안내

TAIPOPO 1.0.0 (17)

최종 수정일: 2026-11-21

1. 앱 계정

타이포포는 별도의 앱 계정을 생성하거나 운영하지 않습니다.

2. 앱 내부에 저장되는 데이터

근무지 정보, 근로자 정보, 출퇴근·업무 기록, 사진, 정산, 리포트, PDF, 앱 설정, 첨부파일, 내보내기/백업 관련 파일은 기본적으로 기기 내부 앱 저장영역을 중심으로 저장됩니다. 현재 확인된 구현 기준으로 앱은 사용자의 업무 기록을 자체 서버에 업로드하여 보관하는 구조가 아닙니다.

3. 앱 내부 데이터 삭제하기

기록은 각 기능에서 개별 삭제할 수 있습니다. 사진은 휴지통으로 이동한 뒤 복원하거나 영구 삭제할 수 있습니다. 기기에 저장된 앱 관리 데이터는 다음 경로에서 삭제할 수 있습니다.

설정 > 데이터 관리 > 전체 데이터 초기화

전체 데이터 초기화는 앱 설정, 업무 데이터, 앱 내부 사진, 앱 내부 생성 PDF, 앱 내부 첨부파일, 앱 내부 내보내기/백업 데이터 및 캐시/임시 데이터를 삭제합니다. 삭제가 완료되면 앱이 종료될 수 있으며, 별도로 보관한 백업이 없는 경우 삭제한 기기 내부 앱 데이터는 복구할 수 없습니다.

4. 앱 삭제

앱을 삭제하면 기기 내부 앱 저장영역의 데이터는 운영체제 정책에 따라 제거될 수 있습니다. 다만 앱 밖으로 내보내거나 복사한 파일, 다른 앱이나 저장장치에 보관된 사본까지 모두 삭제된다는 의미는 아닙니다. 앱 삭제 전에는 필요한 자료를 백업하거나 외부 사본을 직접 정리하세요.

5. 백업 ZIP과 외부 사본

1.0.0(17)은 Google 계정 연결이나 직접 Drive API 백업·복원·자동 업로드 재개를 제공하지 않습니다. 백업 ZIP은 기기에서 만들며 기기나 외장 저장소에 저장할 수 있습니다. 외부 백업을 내보낼 때는 Android 공유창에서 수신 앱을 선택하고, 복원할 때는 기기 백업 목록이나 파일 선택기로 백업을 선택합니다. 이전 버전이 만든 Drive appDataFolder 백업은 공유하여 저장한 일반 ZIP과 별개이며, 업데이트나 로컬 초기화로 자동 삭제되지 않습니다. 이 버전은 그 이전 백업을 직접 조회·삭제하지 않습니다. 도움이 필요하면 문의해 주세요.

6. 앱 외부 파일

사용자가 Downloads 등에 내보낸 파일, 다른 앱으로 공유한 파일, 이메일로 전송한 파일, 클라우드에 복사한 파일, USB·외장 저장장치 또는 사용자가 별도로 보관한 ZIP/PDF/사진은 앱 내부 데이터 삭제와 별개로 남을 수 있습니다. 해당 사본은 저장된 위치나 수신한 서비스에서 별도로 삭제해야 합니다.

7. Firebase Crashlytics 진단 정보

앱의 로컬 데이터를 초기화하거나 앱을 삭제해도, 이미 Firebase Crashlytics로 전송된 진단 정보는 자동으로 삭제되지 않습니다.

이 앱은 Crashlytics에 별도 사용자 ID를 지정하지 않습니다. Firebase 지원팀의 확인에 따라, 현재 구조에서는 FID 또는 Crashlytics 설치 식별자로 특정 이용자의 과거 보고서를 찾아 개별 삭제할 수 없습니다. FID 삭제도 이미 전송된 보고서를 삭제하지 않습니다. 이 제한은 지원 이메일이나 기기 내 업무 기록의 삭제에 적용되는 제한이 아닙니다.

8. 삭제 전 백업

근무 기록, 설정, 사진 등을 백업 ZIP으로 기기에 보관합니다. 백업 ZIP을 만든 뒤 Android 공유창에서 보관할 앱을 선택하세요. 저장 상태는 선택한 앱에서 확인하세요. 분할 백업은 모든 파일을 함께 보관하세요. 복원을 실행하면 현재 기기 데이터가 백업 내용으로 대체될 수 있습니다.

9. 삭제 절차와 문의

앱에 별도 사용자 계정이나 자체 서버 보관 업무 데이터가 없으므로, 기기 내부 앱 데이터는 위의 전체 데이터 초기화로 삭제할 수 있습니다.

문의: taipopo.app@gmail.com

운영자는 문의 처리에 필요한 정보만 사용합니다. 문의 답변과 필요한 후속 조치를 마쳐 처리 목적이 달성되면 문의 정보와 첨부파일을 지체 없이 삭제합니다. 수신·회신 메일은 계정에서 영구 삭제하고, 다운로드 등 운영자가 관리하는 사본도 삭제합니다. 실제 법정 보존 의무가 적용되는 기록만 해당 법정 기간 동안 다른 문의와 분리하여 보관합니다.

삭제 요청은 taipopo.app@gmail.com으로 보내 주세요. 본인 또는 정당한 대리 권한을 확인하는 데 필요한 최소 정보로 확인한 뒤 처리합니다. 법령상 보존해야 하는 기록은 그 의무가 적용되는 범위에서 삭제 대상에서 제외하고, 근거와 보존기간을 안내합니다. Gmail 제공자의 서버와 백업에서 정보를 제거하는 절차는 운영자 관리 사본의 삭제와 구분됩니다.

운영자는 Gmail을 이용하여 문의 메일을 수신·보관하고 답신하며, 운영자의 문의 처리·삭제에는 이 방침을 적용합니다. 발신 단계에는 사용자가 선택한 메일 서비스도 관여하며, 각 메일 서비스 자체의 처리에는 해당 서비스의 정책도 적용됩니다.

앱 이용계약의 이행 또는 계약 체결 과정에서 요청하신 조치에 필요한 지원 문의는 한국 개인정보 보호법 제15조제1항제4호에 따라 처리합니다. 개인정보 권리 행사 요청은 같은 법 제15조제1항제2호 및 제35조부터 제38조까지의 해당 규정에 따라 처리합니다. 각 요청에 필요한 발신 이메일 주소, 문의 내용 및 관련 자료만 처리하며, 일반적인 제안이나 불필요한 첨부에 이 근거를 일괄 적용하지 않습니다.

개인정보 선택은 이 기기에 별도로 저장하며 ZIP 백업에 포함하지 않습니다. 전체 데이터 초기화는 선택을 초기 상태로 되돌립니다. 진단 철회·앱 초기화는 이미 전송된 진단, 외부 공유 사본을 삭제하는 같은 기능이 아닙니다. 미전송 보고서 삭제 요청도 모든 SDK 대기열 삭제 완료를 보장하지 않습니다. 이미 전송한 정보는 문의처로 삭제를 요청할 수 있으며 실제 처리 범위는 서비스와 적용 법령에 따라 확인해야 합니다.

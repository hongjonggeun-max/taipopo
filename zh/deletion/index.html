数据删除指南

TAIPOPO 1.0.0 (17)

最后修订日期：2026-11-22

1. 应用账户

TAIPOPO 不创建或运营单独的应用账户。

2. 应用内部保存的数据

工作地点信息、劳动者信息、考勤和工作记录、照片、结算、报告、PDF、应用设置、附件以及 export/backup 相关文件，主要保存在设备内的应用存储区域。根据目前确认的实现，应用并不是将用户的工作记录上传并保存到自身服务器的结构。

3. 删除应用内部数据

记录可以在各功能中单独删除。照片可以移动到回收站后恢复或永久删除。设备上保存的应用管理数据可以通过以下路径删除。

设置 > 数据管理 > 重置所有数据

重置全部数据会删除应用设置、工作数据、应用内部照片、应用内部生成的 PDF、应用内部附件、应用内部 export/backup 数据以及 cache/temp 数据。删除完成后应用可能会关闭；如果没有单独保存的备份，已删除的设备内应用数据无法恢复。

4. 删除应用

删除应用时，设备内应用存储区域的数据可能会根据操作系统政策被移除。但这并不意味着导出或复制到应用外的文件、保存在其他应用或存储设备中的副本也会全部删除。删除应用前，请备份需要的资料，或自行整理外部副本。

5. 备份 ZIP 和外部副本

1.0.0(17)版本不提供Google账号连接、通过Drive API直接备份或恢复，也不自动续传。备份ZIP在设备上创建，可保存到设备或外部存储。导出外部备份时，请在Android分享面板中选择接收应用；恢复时，可从设备备份列表或文件选择器中选择备份。旧版本在Drive appDataFolder中创建的备份，与通过分享保存的普通ZIP不同，不会因更新或本地重置而自动删除。此版本无法直接列出或删除这些旧备份。如需帮助，请联系支持。

6. 应用外部文件

用户导出到 Downloads 等位置的文件、分享到其他应用的文件、通过电子邮件发送的文件、复制到 cloud 的文件、USB 或外部存储设备，或者用户另行保存的 ZIP/PDF/照片，可能会在应用内部数据删除后仍然保留。此类副本需要在保存位置或接收服务中另行删除。

7. Firebase Crashlytics 诊断信息

重置应用的本地数据或卸载应用，不会自动删除已发送至 Firebase Crashlytics 的诊断信息。

本应用未设置自定义Crashlytics用户ID。Firebase支持团队已确认，在此配置下，无法通过FID或Crashlytics安装标识符查找并单独删除某位用户的历史报告。删除FID也不会删除已发送的报告。此限制不适用于支持邮件或设备内工作记录的删除。

8. 删除前备份

将工作记录、设置、照片等作为备份 ZIP 保存在设备上。 创建备份 ZIP 后，在 Android 分享面板中选择用于保存的应用。请在所选应用中确认保存状态。分卷备份的所有文件须一同保管。 执行恢复时，当前设备数据可能会被备份内容替换。

9. 删除流程和咨询

由于应用没有单独的用户账户，也没有保存在自身服务器上的工作数据，设备内应用数据可以通过上述重置全部数据删除。

咨询：taipopo.app@gmail.com

运营者仅使用处理咨询所需的信息。咨询答复和必要的后续处理完成、处理目的达成后，将及时删除咨询信息和附件。收到的邮件和回复邮件将从账户中永久删除，下载文件等由运营者管理的副本也将删除。仅对实际适用法定保存义务的记录，在法定期限内与其他咨询分开保存。

请将删除请求发送至 taipopo.app@gmail.com。运营者使用必要的最少信息核实本人身份或合法代理权限后处理请求。依法必须保存的记录，仅在该义务适用的范围内不予删除，并说明法律依据和保存期限。Gmail 提供方从其服务器和备份中移除信息的流程，与运营者删除其管理的副本不同。

运营者使用 Gmail 接收、保存和回复咨询邮件，运营者对咨询的处理和删除适用本政策。发送过程中也会涉及用户选择的邮件服务，各邮件服务自身的处理还适用其各自的政策。

为履行应用使用合同，或在订立合同过程中采取您所请求的措施而必需的支持咨询，依据韩国《个人信息保护法》第15条第1款第4项处理。个人信息权利请求依据该法第15条第1款第2项及第35至38条中的适用规定处理。仅处理各项请求所必需的发件人邮箱地址、咨询内容和相关资料，不将这些依据一概适用于一般建议或不必要的附件。

隐私选择单独保存在本设备，不包含在 ZIP 备份中。重置全部数据会恢复初始状态。撤回诊断和重置应用不是同一种删除已发送诊断或外部共享副本的功能。请求删除未发送报告也不确认所有 SDK 队列已删除。可联系我们申请删除已发送信息；实际范围须依据服务和适用法律确认。

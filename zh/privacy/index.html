2. 处理的信息

TAIPOPO 将考勤、工作地点、照片记录、结算和报告管理所需的信息，主要保存在用户设备内的应用存储区域。根据目前确认的实现，TAIPOPO 并不是将用户的工作数据上传并保存到自身服务器的结构。

  • 用户和劳动者信息：劳动者姓名、电话号码、电子邮件、地址和详细地址、工资计算标准、支付日、支付方式、银行、账号、账户持有人
  • 工作地点信息：工作地点名称、地址和详细地址、公司名称、负责人姓名、联系方式、工作地点备忘录以及工作地点附件
  • 考勤和工作记录：上班和下班时间、工作和休息时间、工作备忘录、结算数据、报告数据以及相关记录的状态快照
  • 照片和图像信息：包括原始照片、编辑照片、显示用图像、缩略图等派生图像、用户指定的照片分类、用户添加的照片标记和照片标注信息、拍摄时间，以及与照片关联的工作地点和工作信息
  • 位置和地址信息：用户允许位置权限并使用相关功能时的 GPS 坐标和地址信息。为将坐标转换为地址，应用会调用 Android 操作系统的地理编码服务；根据设备和操作系统的配置，此过程可能会使用网络。 开启地址显示、授予位置权限且有有效坐标时，相机可以请求将坐标转换为地址。仅开启 GPS 记录不会发起地址转换请求。
  • 照片文件的元数据：原始照片文件可能包含 EXIF 等拍摄相关元数据（照片附加信息）。应用可能会读取与图像方向相关的信息，或将其反映到派生图像中，用于照片显示、分享和生成 PDF。
  • 设置和诊断信息：应用设置、通知、相机和备份设置、备份和恢复进度信息、应用稳定性及错误诊断信息

相机地址查询需要开启地址显示、可用的精确位置，以及单独选择允许查询。仅开启GPS记录不会请求地址。每次工作地点GPS请求都会在访问坐标前说明可能在设备外处理并征求查询许可，即使Android权限已经授予也是如此。获准的查询可以使用精确或大致位置。拒绝后仍可手动输入地址。

最近查询的工作地点地址及相关位置信息可能暂时保留在应用内存中。如果满足位置时间、精度和距离条件，可在查询完成后30秒内复用地址，省去新的地理编码请求。30秒是复用期限，并非内存删除时限。此复用缓存不写入文件或备份，也不用于相机地址。您选择保存的工作地点地址会另行存储在设备上。

3. 处理目的与依据

上述信息来源于用户在应用中输入的内容、拍摄的照片、添加的附件，或用户直接运行功能时产生的信息。 信息用于考勤和工作记录管理、照片记录、结算、报告、PDF、备份、恢复、通知、错误诊断和咨询处理。

4. 保存期限

工作数据和照片可能保存在应用内，直至用户删除具体记录、永久删除照片、重置全部数据、卸载应用或通过操作系统清除应用数据。 第10条所述回收站规则和例外同样适用。 重置全部数据会删除设备内应用管理区域中的设置、工作数据、照片、生成的 PDF、附件、应用内部的导出文件、备份数据、缓存和临时文件。 存储在应用管理区域之外的副本需要另行删除。 已导出的 ZIP/PDF/照片及外部存储中的副本须在各自保存位置单独删除。 已发送至 Firebase Crashlytics 的诊断信息按照 Firebase 的功能和政策处理。

设备丢失或故障、卸载应用或清除应用数据可能导致记录和照片丢失。 仅保存在同一设备上的备份也可能一并丢失，请将重要备份另存到设备之外。 您需要检查并管理备份完成状态、保存位置、文件状况及账户访问权限。 开发者不会在单独的服务器上保存记录副本，没有有效备份时可能无法协助恢复。 错误诊断等外部信息处理请参阅隐私政策的相关内容。

5. 备份 ZIP 和外部副本

TAIPOPO 在设备上创建备份 ZIP。导出时，文件会交给您在分享面板中选择的应用。存放在应用外的副本可在其保存位置自行管理或删除。

此标准 ZIP 是备份范围内的工作数据、设置、照片等数据的未加密副本，不包含条款确认或接受记录。它可能包含原始照片及其位置、拍摄时间和设备元数据，以及工作地点、地址、工作记录、工资和备注。保存或分享会在应用外创建一份副本，所选人员或应用可以打开。

1.0.0(17)版本不提供Google账号连接、通过Drive API直接备份或恢复，也不自动续传。备份ZIP在设备上创建，可保存到设备或外部存储。导出外部备份时，请在Android分享面板中选择接收应用；恢复时，可从设备备份列表或文件选择器中选择备份。旧版本在Drive appDataFolder中创建的备份，与通过分享保存的普通ZIP不同，不会因更新或本地重置而自动删除。此版本无法直接列出或删除这些旧备份。如需帮助，请联系支持。

6. Firebase Crashlytics

Firebase Crashlytics 诊断默认关闭。允许后，错误代码、清理后的调用记录、SDK 安装标识符以及设备和应用诊断信息可能发送至 Google Firebase。应用不会将工作记录、照片或咨询正文作为诊断内容发送。不允许诊断也可使用记录、拍照和备份功能。

撤回会阻止应用提交新的错误报告，已在进行中的 SDK 通信无法撤回。撤回或此次更新迁移后重新启动 Firebase 前，会清理保留的 Crashlytics 报告及排队的 Firebase 会话诊断；清理失败时不会开启 Firebase 错误报告。同一应用进程中再次允许时，需完全结束进程并重启、清理后才会应用，以防追溯发送关闭期间的报告。当前配置不支持按特定用户查找或删除过去的单份 Crashlytics 报告。删除 Firebase 安装标识符（FID）不会删除已经发送的历史 Crashlytics 报告。此选择不控制 ML Kit 诊断。 保留的 ML Kit 技术诊断可能单独发送。

Crashlytics 诊断信息与用户的工作记录、照片和结算数据相互区分。重置应用本地数据或卸载应用不会自动删除已发送至 Firebase Crashlytics 的诊断信息。对于发送至 taipopo.app@gmail.com 的咨询，我们会分别说明当前可采取的措施与提供者的限制。

根据 Firebase 官方说明，Crashlytics 会将故障发生时的调用记录及相关标识符保留 90 天，之后开始从运行中的系统和备份系统中删除这些信息。

本应用未设置自定义Crashlytics用户ID。Firebase支持团队已确认，在此配置下，无法通过FID或Crashlytics安装标识符查找并单独删除某位用户的历史报告。删除FID也不会删除已发送的报告。此限制不适用于支持邮件或设备内工作记录的删除。

7. 二维码识别

含有 ML Kit 的版本即使在设备内解码 QR 图像，仍可能在外部处理 SDK 安装标识符、设备、应用及事件等技术诊断信息。Firebase 诊断选择并不控制 ML Kit。

使用 ZXing 的版本在设备上处理二维码图像，并且不使用 ML Kit 扫描二维码。更新应用不会自动删除以前的诊断队列或已发送到服务器的数据。剩余的诊断数据仍可能单独发送。

8. 第三方与外部处理

TAIPOPO不会将工作记录和照片集中保存在自有服务器上，也不会出售这些数据。错误诊断、地址查询、支持邮件和本网站的提供可能涉及外部服务处理信息。各项处理将在下文说明。

Firebase Crashlytics：允许错误诊断后，Google Firebase可能处理错误代码、经过过滤的调用记录、安装标识符以及设备和应用诊断信息。第6节区分撤回同意与删除已发送信息。

Android地址查询：允许地址查询后，应用通过操作系统的地理编码服务将坐标转换为地址。根据设备和操作系统配置，坐标和查询请求可能通过网络处理。仅开启GPS记录不会查询地址。

Google Play：1.0.0(17)的封闭测试PRO配置不会发起应用内商品查询、购买或恢复购买请求。读取设备上已保存的购买权限，与向Google Play发出新请求不同。Play商店自身的下载、更新和账号信息处理属于独立服务，不受TAIPOPO诊断同意设置控制。

邮件支持：发送邮件后，开发者会收到发件地址、正文、附件及您提供的设备信息，用于处理咨询。收到的邮件通过Gmail处理，网站本身没有咨询提交表单。详见第14节。

GitHub Pages：提供网站托管时，GitHub会出于安全目的记录访问者的IP地址。网站访问信息和浏览器主题存储见第13节。

外部分享：分享照片、PDF或备份ZIP时，文件会发送给您选择的接收应用，可能包含照片元数据和工作记录。应用外的副本须在其存储位置或接收服务中管理或删除。

9. 分享与导出照片、PDF 和 ZIP

照片、PDF、ZIP 以及其他 导出 文件，仅在用户直接选择分享、保存或导出操作时，才可能被复制到用户选择的外部应用、存储位置、云存储、USB 或外部存储设备等。传递到应用管理区域之外的副本，其保存和删除范围可能因相关应用、存储位置、服务和用户设置而异。

10. 删除方式与用户权利

移入回收站的项目（包括照片、备忘录、工作地点、结算和报告）可以恢复或永久删除。自删除日期起已在回收站中存放30天的项目，会在此后再次打开回收站时被永久删除；永久删除后无法再从应用回收站恢复。用户也可以在30天期满前主动永久删除项目。

没有删除日期信息的旧项目不适用按期限自动删除。仍被其他记录使用的照片在删除过程中会受到保护。正在恢复数据或无法正常加载记录时，自动清理可能会延后。

用户可以在应用中查看、修改和删除记录，照片可以从回收站恢复或永久删除。重置全部数据会删除设备内应用管理区域中的设置、工作数据、应用内部照片、应用内部生成的 PDF、附件、应用内部的导出文件、备份数据、缓存和临时文件。 设备内由应用管理的数据可通过“设置 > 数据管理 > 重置所有数据”删除。

用户导出到 Downloads 等位置的文件、分享或复制到其他应用、电子邮件、云存储、USB、外部存储设备的 ZIP/PDF/照片，以及已经发送到 Crashlytics 的诊断信息，均与本地重置相互独立。隐私相关咨询及应用数据删除流程咨询可以发送至 taipopo.app@gmail.com。

有关查阅、更正、删除、停止处理、应用数据删除流程说明或由法定代理人行使权利的请求，可发送至 taipopo.app@gmail.com。 在处理请求时，可能需要核验为确认请求人本人身份或合法权限所必需的最少信息。

11. 安全措施与自动收集

应用主要在设备内的应用存储区域管理工作数据和照片。 根据已核实的应用结构，TAIPOPO 不使用自有网页 Cookie 等文件自动收集工作数据。

支持邮箱账户使用两步验证。当前设置中没有获授权代管邮件的用户或转发地址，并已关闭 POP 下载和 Gmail 离线邮件存储。这些设置不会自动保护或删除手动下载或另行保存的文件。咨询信息及外部副本的保留和删除规则在相应章节中另行说明。

12. 儿童与政策变更

TAIPOPO 并非以 14 岁以下儿童为主要使用对象而设计的服务。本政策可能会根据法律、服务或功能变化进行修改，修改内容将通过应用更新或应用内公告进行通知。

13. 网站访问信息与主题存储

网站由 GitHub Pages 托管。GitHub 为安全目的记录访问者的 IP 地址。本站没有账号注册、广告跟踪工具或访问统计脚本。托管服务的处理与保留规则见 GitHub 隐私声明：GitHub

浏览器仅在 taipopo-site-theme 中保存浅色或深色主题选项。清除此网站的浏览器数据可删除该值，也可在浏览器支持时阻止网站存储以拒绝保存。选择浅色模式会更改保存值，并不会删除它。没有存储时网站仍可运行；无法读取已保存选项时默认使用浅色模式。

14. 电子邮件咨询

网站仅打开邮件应用，本身不接收或保存咨询。发送邮件后，开发者会接收并处理发件地址、正文、附件和您发送的设备信息，用于回复、排查问题或处理权利请求。应用中的邮件草稿可能包含应用版本与构建号、Android 版本、设备型号和语言；发送前请检查并删除不必要的信息。收到的邮件通过 Gmail 和您选择的邮件服务按其政策处理。如需了解收件的保留或删除，请联系 taipopo.app@gmail.com。Google 政策：Google

运营者仅使用处理咨询所需的信息。咨询答复和必要的后续处理完成、处理目的达成后，将及时删除咨询信息和附件。收到的邮件和回复邮件将从账户中永久删除，下载文件等由运营者管理的副本也将删除。仅对实际适用法定保存义务的记录，在法定期限内与其他咨询分开保存。

请将删除请求发送至 taipopo.app@gmail.com。运营者使用必要的最少信息核实本人身份或合法代理权限后处理请求。依法必须保存的记录，仅在该义务适用的范围内不予删除，并说明法律依据和保存期限。Gmail 提供方从其服务器和备份中移除信息的流程，与运营者删除其管理的副本不同。

运营者使用 Gmail 接收、保存和回复咨询邮件，运营者对咨询的处理和删除适用本政策。发送过程中也会涉及用户选择的邮件服务，各邮件服务自身的处理还适用其各自的政策。

为履行应用使用合同，或在订立合同过程中采取您所请求的措施而必需的支持咨询，依据韩国《个人信息保护法》第15条第1款第4项处理。个人信息权利请求依据该法第15条第1款第2项及第35至38条中的适用规定处理。仅处理各项请求所必需的发件人邮箱地址、咨询内容和相关资料，不将这些依据一概适用于一般建议或不必要的附件。

Gmail垃圾箱的自动删除期限不是TAIPOPO的咨询保存期限。从账号中永久删除邮件后，Google服务器和备份中的信息删除可能还需要额外时间。服务提供者的保留规则：Google · Gmail删除方法：Gmail

15. 适用法律规定的权利

在适用法律规定的范围内，您可以请求访问、更正、删除、限制处理、提出异议、转移数据，以及撤回基于同意进行处理的同意。撤回不影响此前处理的合法性。请向 taipopo.app@gmail.com 提交请求；可能仅要求核实身份或权限所必需的最少信息。您也可以向有管辖权的数据保护监管机构投诉。欧洲经济区机构目录：EDPB

仅存于设备内的记录由您在应用中管理。使用应用本身不会将这些记录发送给开发者，开发者也无法远程删除。通过邮件或外部服务发送的数据应另行区分。

16. 权限与个人信息处理依据

Android 权限用于启用特定功能，本身并不构成所有个人信息处理的法律依据或概括同意。撤回权限、删除本地记录和删除外部副本是不同操作。外部服务的处理与保留适用其各自政策。

17. 条款接受记录

当前 Play 内部测试 +17 仅提供条款阅览。新的接受步骤和本地记录已加入单独的验证修改版，尚未分发。

为确认适用条款，将接受的条款版本、接受状态与时间、隐私告知版本保存在本设备的应用设置中。仅启动应用或阅览文档不会被记录为接受。运营者不会在服务器上接收这些记录，也不会将其包含在诊断或备份 ZIP 中。

保留应用数据期间，以前的接受记录保留在设备中。普通文字修改与需要重新接受的变更相互区分。重置全部应用数据或卸载应用可能删除本设备的这些记录。运营者不提供远程查看或删除仅存于您设备中的记录的功能。

仅在适用文档及生效日期确定后记录正式接受；其他继续操作的确认不视为正式同意条款。

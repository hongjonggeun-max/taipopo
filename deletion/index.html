데이터 삭제 안내

시행일: 정식 출시일에 맞춰 확정 예정

1. 앱 계정

확인한 앱에는 별도의 TAIPOPO 회원가입 절차나 앱 비밀번호가 없습니다.

Google 연결, Drive 백업·복원 및 백업 관리 등 인증이 필요한 기능에서 사용자가 선택한 Google 계정을 사용합니다. Drive 백업은 appDataFolder를 사용하며 전체 Drive 파일 접근 권한을 사용하지 않습니다.

2. 앱 내부에 저장되는 데이터

근무지 정보, 근로자 정보, 출퇴근·업무 기록, 사진, 정산, 리포트, PDF, 앱 설정, 첨부파일, 내보내기/백업 관련 파일은 기본적으로 기기 내부 앱 저장영역을 중심으로 저장됩니다. 현재 확인된 구현 기준으로 앱은 사용자의 업무 기록을 자체 서버에 업로드하여 보관하는 구조가 아닙니다.

3. 앱 내부 데이터 삭제하기

기록은 각 기능에서 개별 삭제할 수 있습니다. 사진은 휴지통으로 이동한 뒤 복원하거나 영구 삭제할 수 있습니다. 기기에 저장된 앱 관리 데이터는 다음 경로에서 삭제할 수 있습니다.

설정 > 데이터 관리 > 전체 데이터 초기화

전체 데이터 초기화는 앱 설정, 업무 데이터, 앱 내부 사진, 앱 내부 생성 PDF, 앱 내부 첨부파일, 앱 내부 내보내기/백업 데이터 및 캐시/임시 데이터를 삭제합니다. 삭제가 완료되면 앱이 종료될 수 있으며, 별도로 보관한 백업이 없는 경우 삭제한 기기 내부 앱 데이터는 복구할 수 없습니다.

4. 앱 삭제

앱을 삭제하면 기기 내부 앱 저장영역의 데이터는 운영체제 정책에 따라 제거될 수 있습니다. 다만 앱 밖으로 내보내거나 복사한 파일, Google Drive 백업, 다른 앱이나 저장장치에 보관된 사본까지 모두 삭제된다는 의미는 아닙니다. 앱 삭제 전에는 필요한 자료를 백업하거나 외부 사본을 직접 정리하세요.

5. Google Drive 백업

사용자가 직접 생성한 Google Drive 백업은 Google Drive의 앱 전용 appDataFolder에 보관됩니다. 새 Google Drive 백업은 사용자가 시작합니다. 업로드 네트워크 정책이 허용하면 다음 앱 시작 시 조건을 충족하는 중단된 업로드를 자동으로 재개할 수 있습니다. 로컬 전체 데이터 초기화와 Google 계정 연결 해제는 이미 저장된 Drive 백업을 자동으로 삭제하지 않습니다. 완료된 백업은 Google Drive 백업 관리에서 사용자가 특정 백업을 선택하고 삭제를 확인해야 삭제됩니다.

6. 앱 외부 파일

사용자가 Downloads 등에 내보낸 파일, 다른 앱으로 공유한 파일, 이메일로 전송한 파일, 클라우드에 복사한 파일, USB·외장 저장장치 또는 사용자가 별도로 보관한 ZIP/PDF/사진은 앱 내부 데이터 삭제와 별개로 남을 수 있습니다. 해당 사본은 저장된 위치나 수신한 서비스에서 별도로 삭제해야 합니다.

7. Firebase Crashlytics 진단 정보

앱의 로컬 데이터를 초기화하거나 앱을 삭제해도, 이미 Firebase Crashlytics로 전송된 진단 정보는 자동으로 삭제되지 않습니다.

8. 삭제 전 백업

기기 변경, 앱 삭제 또는 전체 데이터 초기화 전에 필요한 기록은 설정 > 백업 및 복구 > Google Drive 백업에서 사용자가 직접 Google Drive에 백업할 수 있습니다. 복원을 실행하면 현재 기기 데이터가 백업 내용으로 대체될 수 있습니다.

9. 삭제 절차와 문의

앱에 별도 사용자 계정이나 자체 서버 보관 업무 데이터가 없으므로, 기기 내부 앱 데이터는 위의 전체 데이터 초기화로 삭제할 수 있습니다. 삭제 절차나 Google Drive 백업 관련 도움이 필요하면 아래 이메일로 문의하세요.

1. 처음 시작 · 설정과 근무지

1. 설정에서 사용할 언어와 통화를 확인하세요. 통화 표시를 바꾸는 것을 환율에 따른 자동 환전으로 생각하면 안 됩니다. 금액을 입력하기 전에 사용할 통화를 정하세요.

2. 메인 상단에서 근무지를 선택하세요. 새 현장은 ‘신규’에서 이름과 필요한 정보를 입력하고 저장합니다. 비슷한 이름의 현장이 있다면 주소나 구분할 수 있는 이름을 사용하세요.

3. 출근·사진·금액을 기록하기 전에 선택된 근무지가 맞는지 다시 확인하세요. 다른 현장의 기록을 찾을 때는 먼저 근무지와 날짜 조건을 확인합니다.

4. 카메라·위치 등 권한 안내가 나오면 해당 기능에 필요한 권한을 선택하세요. 권한을 거절했다면 Android 설정의 앱 권한에서 다시 허용할 수 있습니다. 권한을 허용해도 과거 기록의 정보가 자동으로 채워지는 것은 아닙니다.

2. 메인 화면 · 오늘의 기록

메인은 당일 작업을 정리하는 화면입니다. 전체 누적 청구나 지난 기간의 목록을 보는 화면과 구분하세요. 상단 근무지·날짜를 먼저 확인하고 출퇴근, 총수입, 메모, 사진 카드를 이용합니다.

총수입 카드에서는 임금에 해당하는 수입, 추가 수당, 별도 청구를 구분해서 봅니다. 표시된 금액이 실제로 통장에 입금됐다는 뜻은 아닙니다. 청구의 수령 여부는 별도 청구에서 관리합니다.

연필 아이콘은 수입·수당·청구를 함께 수정하는 화면을 엽니다. 각 영역을 펼쳐 내용을 입력하고 하단 ‘저장’을 누르세요. ‘취소’는 저장을 대신하지 않습니다. 저장 후 메인 또는 해당 목록을 다시 열어 반영된 금액을 확인하세요.

예: 오늘 임금 100,000, 수당 10,000, 대신 지출한 자재비 25,000이라면 세 항목을 구분해서 기록합니다. 같은 자재비를 수당과 청구에 중복 입력하지 마세요.

3. 출퇴근 · 휴게시간과 근무시간

1. 근무지를 확인한 뒤 ‘출근’을 누릅니다. 이미 진행 중인 근무가 있는지 화면의 시각과 상태를 확인하세요.

2. 총 체류시간, 휴게시간, 실제 근무시간은 서로 다릅니다. 실제 근무시간은 출퇴근 사이의 시간에서 반영된 휴게시간을 제외한 값입니다. 단가가 같아도 휴게시간이나 기록된 시각이 다르면 금액이 달라질 수 있습니다.

3. 업무가 끝나면 ‘퇴근’을 누르고 안내에 따라 기록을 마무리하세요. 지난 기록을 수정할 때는 정산에서 정확한 근무지·날짜의 항목을 열고 시각과 휴게시간을 확인합니다. 수정 가능한 항목만 변경하고 저장합니다.

예: 09:00 출근, 18:00 퇴근, 휴게 1시간이면 체류 9시간과 실제 근무 8시간을 구분해야 합니다. 날짜를 넘긴 근무는 종료 날짜도 확인하세요. 누락된 기록을 보정하려고 오늘의 출근·퇴근을 반복해서 누르지 마세요.

4. 수입과 수당 · 입력·수정·삭제

수입은 근무와 급여 기준에 따른 임금이고, 수당은 별도로 더하는 항목입니다. 수당은 먼저 지출한 돈을 돌려받기 위한 별도 청구와 구분해 입력하세요.

1. 메인 총수입의 연필을 누르고 수입 영역에서 단가·금액을 확인합니다. 현재 근무지의 급여 기준과 실제 근무시간도 함께 확인하세요.

2. 수당 영역을 펼쳐 추가합니다. 제목에는 ‘식대’처럼 구분할 이름, 내용에는 지급 사유나 설명, 금액에는 해당 수당 금액을 입력합니다. 여러 수당은 각각 따로 기록하세요.

3. 기존 수당을 수정하거나 삭제한 뒤 저장합니다. 항목 삭제와 페이지 전체 취소는 다릅니다. 저장 후 메인과 연결된 정산·리포트에서 수당과 합계를 확인하세요. 이미 외부로 저장·전송한 PDF는 새 값으로 자동 교체되지 않습니다.

예: 수당 10,000을 12,000으로 고치려면 기존 항목을 수정합니다. 같은 이름으로 12,000을 새로 추가하면 두 항목이 합산될 수 있습니다.

시급 계산은 휴게시간을 뺀 실제 근무시간에서 완료된 분만 사용합니다. 시급 × 근무 분 ÷ 60으로 계산하며 소수점 아래 금액은 버립니다. 예: 시급 12,000, 실제 근무 8시간이면 96,000입니다. 1분 미만의 진행 중 시간은 아직 반영되지 않을 수 있습니다.

5. 별도 청구 · 기록과 수령 처리

별도 청구는 임금이나 일당이 아니라 따로 받아야 할 돈을 관리하는 대장입니다. 예를 들어 사용자가 먼저 지출한 자재비나 교통비를 기록합니다. 앱이 상대방에게 청구서를 자동 전송하거나 돈을 이체하는 기능은 아닙니다.

1. 메인 연필 화면의 청구 영역에서 추가를 누릅니다. 제목, 금액, 메모를 입력하고 필요한 증빙사진을 촬영합니다. 여러 건은 별도 카드로 추가한 뒤 저장하세요.

2. 정산의 ‘별도 청구’ 카드를 누릅니다. 상단 왼쪽에서 근무지를 고른 다음 오른쪽에서 상태를 선택합니다. 목록은 선택 조건에 맞게 날짜순으로 표시됩니다. 긴 근무지명은 일부만 보일 수 있습니다.

3. ‘미수령’은 아직 받지 않은 초기 상태(기존 미청구), ‘청구’는 지급을 요청한 상태, ‘수령’은 받은 상태입니다. 실제 돈을 받은 뒤 해당 항목 상세에서 수령으로 바꾸고 저장하세요. ‘미수령’ 필터에 ‘청구’ 상태까지 모두 포함된다고 생각하지 마세요.

4. 목록을 누르면 상세에서 금액·내용·상태를 수정할 수 있습니다. 25,000을 지출했다면 미수령으로 기록하고, 요청한 뒤 청구로, 실제 받은 뒤 수령으로 변경하는 순서로 관리합니다.

6. 금액 연동과 삭제 · 꼭 알아두세요

금액 수정과 삭제는 서로 다른 규칙을 따릅니다. 별도 청구에서 연결된 원본 기록이 남아 있으면 명시적으로 저장한 수정 내용이 해당 정산 기록에도 반영됩니다. 연결된 기존 리포트에는 해당 청구 금액 변경이 반영됩니다.

리포트는 청구 관리대장을 그대로 복제하는 화면이 아닙니다. 청구 수령 상태, 사진, 문구, 삭제가 모두 함께 바뀐다고 생각하지 마세요. 리포트 금액 연동은 같은 항목과 근무 연결이 확인되는 기존 기록에 적용되며, 관계없는 항목을 이름만으로 연결하거나 삭제한 리포트를 다시 만들지 않습니다.

정산이나 리포트를 삭제해도 별도 청구 목록과 수령 상태는 남습니다. 반대로 청구 관리대장에서 ‘선택 → 삭제’를 해도 정산·리포트는 유지됩니다. 연결 원본이 없어도 남은 청구를 별도로 관리할 수 있습니다.

관리대장 삭제는 ‘돈을 받았다’는 뜻이 아닙니다. 받았다면 수령 상태로 바꾸세요. 관리대장 삭제를 정산 휴지통의 복원과 같은 기능으로 생각하지 마세요. 삭제 전 보관할 내역과 백업을 확인하세요.

7. 사진 · 촬영·미리보기·편집

1. 올바른 근무지를 선택한 뒤 사진 촬영을 엽니다. 증빙에 필요한 내용이 잘 보이도록 촬영하고 저장 결과를 확인하세요. 청구의 사진 촬영 영역에서는 해당 청구와 함께 증빙을 관리합니다.

2. 사진 미리보기는 여러 장이면 가로로 넘겨 확인합니다. 갤러리에서는 근무지·날짜·분류 등 현재 조건을 확인하고 사진을 열어 자세히 봅니다. 썸네일만 보고 원본의 선명도나 전체 구도를 판단하지 마세요.

3. 사진의 정보카드나 메모 등을 편집했다면 저장한 뒤 상세 화면을 다시 열어 확인합니다. 편집 이미지와 최초 촬영 원본은 구분됩니다. 원본 보기·원본 복구 안내가 나오면 어떤 편집이 제거되는지 확인하세요.

4. 첨부 미리보기의 제거와 갤러리 사진 삭제는 같은 범위라고 단정하지 마세요. 해당 확인창을 읽고 실행합니다. 공유 전에는 위치·촬영시각·기기정보나 사진 속 개인정보를 확인하세요. 이미 공유한 외부 사본은 앱에서 수정·삭제해도 함께 바뀌지 않습니다.

8. 메모 · 작성과 확인

메인 메모 카드에서 추가 기능을 열고 업무 내용이나 전달사항을 적어 저장합니다. 예: ‘동쪽 구역 작업 완료, 자재 추가 주문 필요’처럼 나중에 알아볼 수 있는 내용으로 작성하세요.

메모가 여러 개라면 필요한 항목을 열어 수정하고 저장합니다. 현재 선택한 근무지와 날짜가 맞는지 확인하세요. 다른 날의 내용을 오늘 메모에 반복해서 적기보다 원래 기록을 찾아 수정하는 편이 혼동을 줄입니다.

메모의 숫자는 수당이나 청구 금액 입력을 대신하지 않습니다. ‘교통비 20,000’이라고 메모해도 금액 항목이 자동 생성된다고 생각하지 마세요. 정산에 필요한 금액은 해당 수당·청구 입력란에 별도로 기록합니다.

삭제할 때는 대상 메모를 확인하고, 복원이 필요하면 설정의 휴지통에서 해당 범주를 확인하세요. 비밀번호·인증번호 등 민감한 정보는 업무 메모에 남기지 않는 것이 좋습니다.

9. 정산 · 기간별 조회와 수정

하단 ‘정산’에서 근무지와 일간·주간·월간 등 필요한 조회 범위를 고릅니다. 검색 조건도 함께 적용될 수 있으므로 목록이 비어 있으면 날짜와 근무지, 검색 조건을 순서대로 확인하세요.

목록 카드를 누르면 해당 기록의 상세 내용을 확인할 수 있습니다. 날짜, 근무시간, 단가, 수당, 청구 등 수정하려는 항목을 확인한 뒤 저장하세요. 같은 날짜의 카드가 여러 개면 근무지와 기록 내용을 비교하고 선택합니다.

메인은 당일 기록, 정산은 기간별 기록, 별도 청구는 계속 쌓이는 받을 돈의 관리대장이라는 차이가 있습니다. 별도 청구 필터의 상태와 정산의 날짜 조건을 혼동하지 마세요.

수정 후 목록과 상세를 다시 열어 값을 확인합니다. 리포트까지 확인할 때는 같은 근무 기록에 연결된 문서를 선택하세요. 정산 삭제는 별도 청구 대장의 삭제가 아니며, 선택 삭제 전에 선택 개수와 대상을 확인해야 합니다.

10. 리포트 · 버전·PDF·공유

하단 ‘리포트’에서 원하는 근무지·기간의 문서를 찾고 엽니다. 문서의 근무일, 수입·수당·청구 금액과 첨부사진을 먼저 확인하세요. 리포트는 실제 은행 입금 내역이나 청구 수령 상태를 자동 확인해 주지 않습니다.

저장된 리포트는 수정에 따라 새 버전이 생길 수 있습니다. 이전 버전과 최신 버전을 구분하고, 연결된 청구 금액을 수정했다면 최신 문서에서 확인하세요. 예전에 저장한 버전이나 PDF까지 같은 내용으로 덮어쓰는 것은 아닙니다.

PDF 미리보기에서 글자·사진·금액을 확인한 뒤 저장하거나 공유합니다. 내용 수정 뒤 다시 보낼 때는 최신 값으로 PDF를 새로 생성하세요. 다운로드 폴더나 메신저에 이미 있는 파일은 앱 안의 변경을 자동으로 따라가지 않습니다.

리포트를 삭제해도 별도 청구 관리대장은 남습니다. 앱에서 문서를 삭제하는 것만으로 상대방에게 보낸 파일이나 다른 앱에 저장한 사본이 삭제되지는 않습니다. 공유 전에 개인정보와 수신 대상을 확인하세요.

11. 백업과 복구 · 교체 전 필독

백업은 기기 분실·고장·앱 삭제에 대비한 별도 사본입니다. 기기 내부에만 보관하면 그 기기를 잃었을 때 함께 잃을 수 있습니다. 설정의 백업 메뉴에서 기기 저장, 외부 백업 또는 Google Drive 등 원하는 방식을 선택합니다.

백업 완료 안내와 저장 위치·날짜를 확인하세요. 분할 백업이면 같은 백업에 속한 모든 파일을 함께 보관합니다. 이름을 바꾸거나 일부만 옮기지 말고 복구 화면에서 요구하는 전체 파일 또는 완전한 폴더를 선택하세요. Drive는 선택한 Google 계정과 인터넷 연결을 확인합니다.

중요: 복구는 현재 앱 데이터를 백업 내용으로 교체할 수 있습니다. 두 기기의 새 기록이 자동으로 합쳐진다고 생각하지 마세요. 복구 전에 현재 데이터도 별도로 백업하고, 가져올 백업 날짜와 대상을 확인한 뒤 안내에 따라 진행합니다. 진행 중 앱 데이터 삭제나 저장장치 분리를 피하세요.

완료 후 안내에 따라 앱을 다시 열고 근무지·최근 기록·사진·수당·청구·리포트를 확인합니다. 표준 ZIP 백업은 암호화되지 않은 개인정보 사본일 수 있으므로 공유 대상과 저장 장소를 신중하게 선택하세요. 오류가 나면 기존 백업을 지우지 말고 오류 문구와 선택한 파일 구성을 확인하세요.

SD 카드·USB: 기기에서 지원하는 저장장치를 연결한 뒤 설정의 백업·복구에서 SD 카드·USB 백업 또는 복구를 선택하고 시스템 파일 선택기에서 해당 저장장치의 폴더를 지정합니다. 외부 파일로 받은 백업은 외부 백업 복구 메뉴에서 선택합니다. 기기·연결 방식·쓰기 권한에 따라 이용 가능 여부가 달라지며, 저장 완료를 확인하기 전에는 연결을 해제하지 마세요.

12. 휴지통 · 선택·복원·영구 삭제

설정 → 휴지통에서 갤러리·근무지·메모·정산·리포트 중 원하는 범주를 엽니다. 항목의 체크박스로 선택하거나 ‘전체 선택’을 누릅니다. 전체 선택은 현재 범주에만 적용됩니다.

잘못 삭제했다면 보관 중인 항목을 선택하고 ‘복원’을 누릅니다. 복원 후 원래 목록에서 조회 조건을 맞춰 다시 확인하세요. 필요 없는 항목은 대상을 확인한 뒤 ‘영구 삭제’를 선택합니다.

일반적으로 삭제된 항목은 30일 보관되며, 기간이 지난 항목은 휴지통을 열 때 정리됩니다. ‘25일 후 영구 삭제’처럼 남은 기간을 확인하세요. 삭제 시각 정보가 없는 예전 항목은 자동 정리에서 제외될 수 있습니다.

영구 삭제한 항목은 휴지통에서 복원할 수 없습니다. 다른 기록에서 사용하는 사진은 보호될 수 있습니다. 별도 청구 관리대장의 삭제는 이 범주의 정산 삭제와 별개입니다. 전체 데이터 초기화나 외부 백업 삭제도 휴지통 복원과 혼동하지 마세요.

13. 문제 해결 · 확인 순서와 문의

금액이 다르다면 ① 근무지·날짜·통화 ② 출퇴근·휴게시간·단가 ③ 수당·청구 중복 ④ 저장 여부 ⑤ 같은 기록에 연결된 최신 리포트인지 순서대로 확인하세요. 이미 받은 돈인지 여부는 청구 상태와 실제 입금 내역을 별도로 확인합니다.

목록이 비어 있다면 근무지·기간·상태·검색 조건을 해제하거나 바꿔 보세요. 다른 범주로 삭제한 기록은 휴지통에서 확인합니다. 사진이 보이지 않으면 원래 근무지·분류와 백업에 사진이 포함됐는지 확인하세요.

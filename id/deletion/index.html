Panduan Penghapusan Data

Tanggal berlaku: akan dikonfirmasi sebelum rilis resmi

1. Akun Aplikasi

Aplikasi yang ditinjau tidak memiliki pendaftaran TAIPOPO terpisah atau kata sandi aplikasi sendiri.

Akun Google pilihan digunakan untuk koneksi Google, cadangan Drive, pemulihan dan pengelolaan cadangan saat autentikasi diperlukan. Cadangan menggunakan appDataFolder, bukan akses ke semua file Drive.

2. Data yang Disimpan di Dalam Aplikasi

Informasi tempat kerja, informasi pekerja, catatan kehadiran dan kerja, foto, perhitungan upah, laporan, PDF, pengaturan aplikasi, lampiran, dan file terkait export/backup disimpan terutama di area penyimpanan aplikasi pada perangkat. Berdasarkan implementasi yang saat ini telah dikonfirmasi, aplikasi tidak memiliki struktur untuk mengunggah dan menyimpan catatan kerja pengguna di server miliknya sendiri.

3. Menghapus Data di Dalam Aplikasi

Catatan dapat dihapus satu per satu di setiap fitur. Foto dapat dipindahkan ke tempat sampah lalu dipulihkan atau dihapus permanen. Data yang dikelola aplikasi dan tersimpan di perangkat dapat dihapus dari jalur berikut.

Pengaturan > Backup dan Pemulihan > Pengelolaan Data > Reset Semua Data

Reset Semua Data menghapus pengaturan aplikasi, data kerja, foto di dalam aplikasi, PDF yang dibuat di dalam aplikasi, lampiran di dalam aplikasi, data export/backup di dalam aplikasi, dan data cache/temp. Setelah penghapusan selesai, aplikasi dapat ditutup, dan jika tidak ada backup yang disimpan terpisah, data aplikasi di perangkat yang sudah dihapus tidak dapat dipulihkan.

4. Menghapus Aplikasi

Saat aplikasi dihapus, data di area penyimpanan aplikasi pada perangkat dapat dihapus sesuai kebijakan sistem operasi. Namun, ini tidak berarti file yang diekspor atau disalin ke luar aplikasi, backup Google Drive, atau salinan yang disimpan di aplikasi atau perangkat penyimpanan lain juga semuanya dihapus. Sebelum menghapus aplikasi, cadangkan materi yang diperlukan atau rapikan salinan eksternal secara langsung.

5. Backup Google Drive

Backup Google Drive yang dibuat langsung oleh pengguna disimpan di appDataFolder khusus aplikasi di Google Drive. Backup dibuat hanya ketika pengguna langsung menjalankan fitur tersebut dan bukan unggahan otomatis. Reset Semua Data lokal dan pemutusan koneksi akun Google tidak otomatis menghapus backup Drive yang sudah tersimpan. Backup yang selesai dihapus hanya ketika pengguna memilih backup tertentu di pengelolaan backup Google Drive dan mengonfirmasi penghapusan.

6. File di Luar Aplikasi

File yang diekspor ke Downloads, file yang dibagikan ke aplikasi lain, file yang dikirim melalui email, file yang disalin ke cloud, USB atau perangkat penyimpanan eksternal, atau ZIP/PDF/foto yang disimpan terpisah oleh pengguna dapat tetap ada terpisah dari penghapusan data di dalam aplikasi. Salinan tersebut harus dihapus secara terpisah di lokasi penyimpanan atau layanan penerima.

7. Informasi Diagnostik Firebase Crashlytics

Mengatur ulang data lokal aplikasi atau menghapus instalasi aplikasi tidak otomatis menghapus informasi diagnostik yang sudah dikirim ke Firebase Crashlytics.

8. Backup Sebelum Penghapusan

Sebelum mengganti perangkat, menghapus aplikasi, atau mereset semua data, pengguna dapat langsung mencadangkan catatan yang diperlukan ke Google Drive dari Pengaturan > Backup dan Pemulihan > Backup Data. Menjalankan pemulihan dapat mengganti data perangkat saat ini dengan isi backup.

9. Prosedur Penghapusan dan Kontak

Karena aplikasi tidak memiliki akun pengguna terpisah atau data kerja yang disimpan di server miliknya sendiri, data aplikasi di perangkat dapat dihapus menggunakan Reset Semua Data di atas. Jika memerlukan bantuan terkait prosedur penghapusan atau backup Google Drive, hubungi email di bawah.

Kontak: taipopo.app@gmail.com

شروط استخدام TAIPOPO

مسودة للمراجعة · الإصدار v2026-11-07. لم يُؤكد تاريخ السريان بعد. تاريخ الإصدار أو المراجعة هذا ليس تاريخ سريان ولا يغير تاريخ سريان سياسة الخصوصية.

تاريخ السريان: يتم تأكيده قبل الإصدار الرسمي

تحدد هذه الشروط استخدام TAIPOPO ("التطبيق") وحقوق المستخدم وواجباته ومسؤولياته. باستخدام التطبيق أو تثبيته، يوافق المستخدم على هذه الشروط.

1. الغرض والنطاق

يساعد التطبيق المستخدم على إدارة مواقع العمل، والحضور، وسجلات العمل، والصور، والتسويات، والتقارير، والنسخ الاحتياطي، والإعدادات ذات الصلة على جهازه. قد تتغير الميزات والشاشات من خلال تحديثات التطبيق.

2. مسؤولية المستخدم

يتحمل المستخدم مسؤولية دقة وقانونية وصلاحية المعلومات التي يدخلها أو يلتقطها أو يرفقها أو يشاركها، ويجب ألا يستخدم معلومات تنتهك خصوصية الآخرين أو حقوقهم.

3. الصور والسجلات والمستندات

يدير المستخدم الصور والسجلات والتسويات والتقارير التي ينشئها التطبيق أو يحتفظ بها. سجلات التطبيق وملفات PDF مخصصة لتسهيل إدارة العمل ولا تضمن أثرا قانونيا أو استيفاء متطلبات أي جهة.

4. التخزين والنسخ الاحتياطي

تخزن البيانات افتراضيا على جهاز المستخدم وقد تضيع بسبب فقدان الجهاز أو تعطله أو حذف التطبيق أو تنظيف النظام أو إعادة التعيين. يجب حفظ البيانات المهمة بشكل منفصل باستخدام Google Drive backup أو نسخ الجهاز أو التخزين الخارجي أو المشاركة أو التصدير.

5. Google Drive والمشاركة الخارجية

لا تتم عمليات Google Drive backup/restore أو النسخ المحلي أو الخارجي أو مشاركة وتصدير الصور والملفات وPDF إلا عندما يبدأها المستخدم مباشرة. حذف بيانات التطبيق أو التطبيق نفسه لا يحذف تلقائيا نسخ Google Drive أو الملفات المنسوخة خارج التطبيق.

6. الأذونات

تستخدم أذونات الكاميرا والموقع والصور أو التخزين والإشعارات للميزات ذات الصلة. قد تتقيد الميزات إذا رفض المستخدم الإذن أو سحبه.

7. الاستخدام المحظور

يحظر الاستخدام غير القانوني، أو الوصول غير المصرح به إلى حسابات أو أجهزة أو معلومات الآخرين، أو تعطيل التطبيق أو تجاوز الأمان، أو نشر برامج خبيثة أو معلومات كاذبة أو مواد تنتهك الحقوق.

8. التغيير أو الإيقاف

يجوز ل TAIPOPO تغيير الميزات أو إضافتها أو إيقافها للأمان أو التحسين أو التشغيل أو الامتثال القانوني، وسيتم إبلاغ التغييرات المهمة قدر الإمكان.

9. المسؤولية

ضمن الحد الذي يسمح به القانون، لا يتحمل TAIPOPO مسؤولية الخسائر الناتجة عن أخطاء المستخدم أو أعطال الأجهزة أو الشبكات أو الخدمات الخارجية أو عدم النسخ الاحتياطي أو المشاركة غير المصرح بها أو مخالفة هذه الشروط. لا يحد ذلك من المسؤولية التي لا يمكن استبعادها قانونا.

10. الخصوصية

تخضع معالجة المعلومات الشخصية والأذونات والتخزين والحذف لسياسة الخصوصية ودليل حذف البيانات في التطبيق.

11. القانون والتواصل

تخضع هذه الشروط لقوانين جمهورية كوريا، ويحدد القانون المختص جهة الفصل في النزاعات. للاستفسارات: taipopo.app@gmail.com
